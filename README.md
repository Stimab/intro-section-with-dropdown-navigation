# Responsive Navigation Landing Page

A responsive landing page featuring interactive dropdown navigation for desktop and mobile layouts.

## Live Demo

https://intro-section-with-dropdown-navigat-topaz.vercel.app

## Features

- Responsive desktop and mobile navigation
- Interactive dropdown menus
- Mobile navigation experience
- Responsive hero section
- Hover and focus states
- Modern responsive layout

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Vercel

## What I Practiced

This project strengthened my understanding of responsive layouts, navigation state, dropdown interactions, mobile-first thinking and accessible interactive UI patterns.

## Run Locally

1. Clone the repository.
2. Open the project in VS Code.
3. Start it with a local development server.
4. Open the local URL in your browser.
